# ANOM 自社サイト v11

オーナーのデザイン画像（PC・スマホ）をもとに作った、問い合わせにつなげるための自社サイトの新しい版です。
既存の本番サイト（リポジトリのルート）とは別のフォルダで、確認用として作っています。本番には公開していません。

## ページの構成

1. ヘッダー（課題／できること／サービス／理念／お問い合わせ、無料相談をする）
2. ファーストビュー: 見出し、AIの横顔（canvas）、漂う悩みチップ9個
   - チップを選ぶと「この悩みに対応するサービス」が切り替わる（PC はチップからカードへ線が伸びる）
   - カードからサービス欄へ移動すると、そのサービスの詳細が開いた状態で表示される
   - 選んだ悩みは、サービス欄の同じタグの強調と、お問い合わせフォームの初期選択に引き継ぐ
3. その悩みを、実装できる解決策へ（3ステップ）
4. サービス内容（AI導入支援／業務自動化／Web・DX設計／問い合わせ導線改善）
5. 理念
6. お問い合わせ（確認用。どこにも送信しない）
7. 画面下の相談バー（無料相談・お問い合わせ／サービスを見る）

## 主なファイル

| 場所 | 内容 |
|---|---|
| `src/data/site.ts` | 文言のすべて（悩みとサービスの対応もここ） |
| `src/components/` | 各セクションの部品 |
| `src/scripts/` | 動きと操作（悩みチップ、横顔の canvas、メニュー、フォームなど） |
| `src/styles/global.css` | 色・書体・角丸・影・動きの値（`@theme`） |
| `public/_headers` | CSP などの応答ヘッダー |
| `public/fonts/` | 自己配信フォントと、その取得元・ライセンスの記録 |
| `tests/` | ブラウザーテスト（Playwright + axe-core） |

## 手元で確かめる

Node は `.nvmrc` の版を使います。

```
npm ci
npm run build
npm run preview    # http://127.0.0.1:8789/ で dist/ を配信（CSP も本番と同じ形で付く）
npm run test:e2e   # 別のターミナルで。preview が動いていなければ自動で起動する
```

作業ルールは [AGENTS.md](./AGENTS.md) を参照してください。
